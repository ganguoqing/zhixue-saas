# M0 PoC 授权清单

这是待项目负责人填写的授权缺口，不是已完成的质量结论。未获授权前，不使用真实学生答卷，不编造解析、匹配或成本指标。

| 需要负责人提供的项 | 用途 | 当前状态 |
|---|---|---|
| 试卷文件及允许使用的环境 | 最小解析、拆题 | 未提供 |
| 标准答案及题号对应 | 答案匹配与异常样本 | 未提供 |
| 允许调用的模型端点、账号和费用上限 | 耗时与成本记录 | 未提供；当前只使用本机 mock |
| 合成答卷是否可代替真实学生卷 | 避免学生数据进入 PoC | 未确认 |
| 人工验收人 | 查看解析和匹配结果 | 项目负责人 |

开发者在授权到达后，只用合成答卷跑已授权端点，并记录失败样例、耗时和费用。Docker Compose 的 PostgreSQL 16.10 与 CI 的 Python 3.12 剖面也不能用本机 PostgreSQL 17.11 / Python 3.14.4 代替。
