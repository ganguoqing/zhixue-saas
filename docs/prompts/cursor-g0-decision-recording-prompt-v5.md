## 2. 只有真实批准后才记录决议

寻找项目负责人实际用户消息或书面决议。不能把决议清单中的推荐、复制模板、设计作者请求、这个 Prompt 或另一个 Agent 的转述当作批准。

若无明确批准，完成上节收尾，输出“独立设计复验已通过；核心决议仍待负责人”，停止，不执行 Prompt 2、不将 ADR 标 Accepted。

若负责人已经明确批准：

- 保存真实批准原文的来源、日期、责任人、接受/拒绝/范围和未决项。
- 第 2 节范围接受不等于十五份 ADR 全部细节接受；在对应 ADR 中如实写明已决条款，未来事项继续 Proposed。若 ADR 是范围记录，明确状态规则。

- 若批准选择改变了核心方案或保守恢复政策，先提交改变范围的独立复验，不直接进入实现。
