# ADR-011 时间有效关系、名单快照与历史访问

- **状态：** Proposed（2026-10-12 修订，未签署）
- **2026-10-13 M0 范围：** 项目负责人在对话中批准决议清单第 2 节对本 ADR「建议批准」列的条款，并接受第 3 节保守恢复政策。见 `g0-decision-record-20261013.md`。同表「仍保留待定」列和未列入的未来细节仍是 Proposed。本 ADR 整体不是 Accepted。
- **日期：** 2026-10-11；修订 2026-10-12
- **2026-10-12 撤回：** 跨版本 `UNIQUE(tenant, exam, student)`。现行唯一键在 `roster_version_id` 内。发布前 `CorrectMatch`，发布后 `OpenAttributionCorrection`。半开区间与授权独立于任课仍然保留。
- **决策责任：** 项目负责人
- **关联：** R12、R13、R14、R11；F02、F18
- **证据：** 已确认转班后历史成绩仍属当时班级，任课变化不改写历史教学事件。班级挂在学年还是学期上，确认记录同时出现两种简图，需要决议。

## 问题

用当前班级重算历史，统计会漂移。把任课关系直接当访问权，会让新教师看见前任的考试，或让离任教师继续看见数据。

## 方案

### A. 推荐：学年班级 + 半开区间 + 名单快照 + 独立授权

- 班级属于学年和年级，学期不拥有班级行。
- 入班、任课使用 `[valid_from, valid_to)`。行政入班禁止重叠。
- 同日转班在时刻 T 关闭旧行并打开新行。
- `exam_roster_entries` 冻结班级与学号，之后不更新。
- 教学事件目标同样快照。
- `teaching_assignments` 不授权。`data_scope_grants.include_historical` 默认 false。
- 离任关闭授权区间，不自动保留访问。
- 补录不改已冻结名单。

### B. 每个学期重建行政班

更贴近 V1.0 §4.1 的树。升学期会产生更多班级行。历史仍必须快照，不能只靠“当前学期班级”。若学校行政班按学期拆分，可以接受 B，但快照规则不变。

### C. 当前班级反写历史考试

与 R13 冲突。禁止。

## 代价

方案 A 下，跨学期仍是同一个行政班，学期分析要按考试 `held_at` 落入哪个学期来过滤，而不是按班级外键。授权与任课分离会让“安排任课”的命令默认不同时授权，产品上应在同一屏幕显式勾选授权，避免管理员以为已经授权。

## 兼容与回退

若从 A 改到 B，应新建学期班级并迁移未冻结关系，已冻结名单保持不动。

## 故障模型

重叠入班、区间端点、转班后旧考试改挂新班、新教师读到前任考试、离任教师令牌仍可用、补录改写名单、同名学生匹配出名单外的人。

## 验收

转班、升班、跨学期任课、补录和区间端点样例保持历史归属。非法重叠被拒。授权用例与任课用例分开。测试未运行。
