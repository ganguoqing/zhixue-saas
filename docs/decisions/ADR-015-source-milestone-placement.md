# ADR-015 已确认数据来源与里程碑落位

- **状态：** Proposed（2026-10-12 修订，未签署）
- **2026-10-13 M0 范围：** 项目负责人在对话中批准决议清单第 2 节对本 ADR「建议批准」列的条款，并接受第 3 节保守恢复政策。见 `g0-decision-record-20261013.md`。同表「仍保留待定」列和未列入的未来细节仍是 Proposed。本 ADR 整体不是 Accepted。
- **日期：** 2026-10-11；修订 2026-10-12
- **2026-10-12：** 来源清单不减。总分 Excel 的正式路径是 `basis_mode=total_only`，见数据字典 v2 第 6 节。写了枚举不等于 v1 已经能发布。
- **决策责任：** 项目负责人。本 ADR 不新增、不取消产品范围，只把已确认来源放到阶段上。
- **关联：** R03、R05、R06、R07、R08、R16、R21、R22；F06、F27

## 问题

若实现只做“新答卷 OCR 再 AI 评分”，学校已有的 Excel、Word 答案和教师已批改卷会被漏掉。若 M0 把这些全部做成产品，又会超出窄切片。

## 方案

### A. 推荐：全部保留，按阶段实现

| 已确认能力 | 阶段 | 规则 |
|---|---|---|
| 无学生端、无在线答题 | 全阶段不做 | 在线答题只预留枚举，不建功能 |
| 学生 Excel 导入 | M1 | 预览、显式行确认、重复键冲突 |
| AI 生成题审核、三级题库 | M2 | 未审核不能入可冻结卷 |
| Word 与手工标准答案 | M3 | 版本化，教师确认后才冻结 |
| 答题卡、已批改卷、整卷手写的逐步完善 | M3 起 | 已批改卷提取教师分，不默认 AI 重评。整卷手写不承诺首期可靠 |
| Excel 逐题与 Excel 总分 | M3 | 总分只做有限证据，不生成逐题和知识点掌握 |
| 练习/材料下载打印 | M5 | 教师审核后导出。不发给学生端 |
| 订阅支付 | 不做 | R25 已排除 |

M0 只验证任务、隔离、文件和 schema，使用合成答卷加上已授权的真实试卷/答案。

### B. 把未写入 V1.0 正文的来源视为删除

与“后续口径只有明确更改才能取代确认记录”冲突。不推荐。

### C. M0 实现完整三种导入和阅卷台

与 M0 窄切片冲突。不推荐。

## 代价

M3 的范围大于“只做 AI 新答卷”。这是确认记录的范围，不是本 ADR 加出来的功能。Word 解析质量要单测，失败时允许教师改用手工录入，不能因此删掉 Word 来源。

## 兼容与回退

来源种类用枚举。新增来源是 expand。停用某种来源需要用户明确更改需求，并保留已导入历史的解释。

## 故障模型

总分被写成知识点证据、已批改卷被 AI 覆盖、未审核生成题进入考试、学生端路由被提前加上、M0 范围膨胀到完整工作台。

## 验收

三种学习数据来源都能经过身份、复核和确认进入正式成绩模型；Word/手工答案能冻结；未审核生成题不能入卷；无学生角色。实现与测试都还未做。
